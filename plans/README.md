## Findings considered and rejected

(So nobody re-audits these.)

- **API response compression (gzip middleware)**: production sits behind Cloudflare, which compresses JSON at the edge; adding `compression` at the origin is likely redundant. Verify at the Caddy/Cloudflare layer if payloads look uncompressed — don't add middleware first.
- **Security headers / helmet**: JSON-only API behind Caddy + Cloudflare; header ownership belongs to that layer. LOW-confidence finding; investigate what Caddy already sets before adding anything at the origin.
- **Framework major upgrades (Express 5, React 19, Tailwind 4, Mongoose 9, react-router 7)**: all one major behind, none EOL, no security cutoff, repo-wide blast radius. No forcing function today. Revisit Express 4→5 first when an advisory lands. Cheap hygiene exception: bump `@tiptap/*` patches together (3.27.1 → 3.27.4+).
- **Splitting the 2,399-line `seedDemo.ts`**: dev-only seed script off every request path; not worth the churn.
- **Front/shared type dedup**: already documented as a 5-item follow-up list in `MIGRATION.md`; constraints haven't materially diverged. Track there, not here.
- **Awareness ghost-carets** (server never broadcasts awareness removal on disconnect; idle carets vanish at ~30 s): real but cosmetic, MED effort in protocol-sensitive code. Deferred — noted in plan 004's maintenance notes.
- **Yjs room-cache TTL/sweep** (possible slow leak on abnormal disconnects): LOW confidence, happy-path eviction looks correct. Investigate only if Pi memory pressure is observed.
- **Campaign export streaming / pretty-print removal** and **CampaignMap O(n²) layout worker**: real but scaling-cliff items, not today-problems. Revisit when campaign sizes warrant.
- **ESLint/Prettier/pre-commit**: worthwhile but MED-risk churn (repo-wide reformat) and the operator didn't select it this round. Candidate for a future run; add a `lint` CI step when it lands.
- **login/verify passkey-enumeration message**: not rejected — folded into plan 002 (Step 3).
